# Personal WEBSITE

Простой адаптивный сайт-визитка на HTML и CSS. Без зависимостей и сборки.

## Просмотр

Откройте `index.html` в браузере.

## Настройка

- В `index.html` замените «Ваше имя», описание, историю и навыки.
- Замените `hello@example.com` в тексте ссылки и в `mailto:` своим адресом. До замены ссылка ведёт на шаблонный адрес.
- Обновите заголовок `<title>` и метаописание `description`.
- Вместо декоративного силуэта можно добавить свою фотографию.
- Цвета и оформление задаются в `styles.css`.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните. После публикации GitHub покажет адрес сайта.
